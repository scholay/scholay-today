# scholay today：平台能力第一批

## 入口

- 设置 → 平台与授权：知乎 Access Secret、微信公众号 WechRss。连接器可用、凭证已配置、在线验证与最近抓取分别展示，不把浏览器登录误报为接口授权成功。
- 设置 → 智能体与目录：MCP 开关、独立写权限、可复制客户端配置、目录层级、订阅恢复与操作记录。
- 文章工具栏 → 图文结构化导出：使用当前 Reading / Web / AI formatted 对应的内容来源。

沿用已有界面设计、字号和三种阅读模式。私人邮箱没有重新接入。

## MCP

服务名和客户端配置项统一为 `scholay-today`，展示名为 `scholay today`。
兼容保留可执行文件名 `scholay-mcp` 和原有本地连接端点；已有客户端在应用改名后
需要将命令路径更新为新应用内的实际路径，可重新复制设置里的配置。

使用官方 Rust MCP SDK，通过 stdio 适配器与正在运行的桌面应用通信。应用仍是数据库的写入入口。适配器不直接打开数据库，不执行任意脚本，不读取平台密钥。

应用在 macOS/Linux 私有 Unix socket（0600）或 Windows 当前账户专用命名管道上提供服务；没有开放 TCP 或公网端口。默认关闭，读写开关分开控制。在设置复制本机实际安装路径对应的 JSON 配置，交给支持本地 stdio MCP 的客户端。应用退出时不可操作。Windows 构建及可选连接器安装见 [Windows 说明](windows.md)。

工具：

| 工具 | 能力 |
| --- | --- |
| `library_list` | 当前订阅、嵌套文件夹、已归档订阅和资料库版本号 |
| `feed_add` | 添加公开的直接 RSS / Atom 地址；重复地址复用已有订阅 |
| `library_apply` | 批量预览或原子提交订阅、文件夹变更 |

`library_apply` 支持 `create_folder`、`rename_folder`、`move_folder`、`delete_folder`、`rename_feed`、`move_feed`、`set_feed_url`、`set_feed_interval`、`archive_feed` 和 `restore_feed`。

使用流程：先 `library_list` 获取稳定 ID 和 `revision`，再用 `dry_run: true` 预览，提交时显式 `dry_run: false`，携带 `expected_revision` 和唯一 `request_key`。不确定请求是否完成时，用同一个 `request_key` 重试；相同键不允许换另一批操作。

删除订阅采取归档：停止刷新、从订阅列表隐藏，但文章、星标和阅读记录保留。删除文件夹将其订阅与子目录移到顶层，不删除文章。循环目录和失效 ID 会拒绝，批量失败全部回滚。

V1 边界：文件夹名称仍全局唯一；本地回环连接器从桌面添加，智能体只可添加公开地址；OPML 仍是原有平面目录导入导出，完整层级以应用数据库和 MCP 为准。旧版独立 CLI 不理解新归档状态，不应混用。Product Hunt 的旧授权入口暂保留在热榜来源页。

## 平台授权

知乎调用本机已安装的官方 CLI。新凭证通过 stdin 传递，保存到 CLI 管理的系统钥匙串；状态返回只包含允许展示的字段。点击在线验证才联网验证凭证。

微信调用本机 WechRss 的健康和抓取状态接口，点击授权在独立窗口打开连接器的扫码管理页。凭证仍由连接器保管，不复制到 RSS 数据库。扫码本身由用户完成；未安装、离线、过期、风控不等同于登录成功。

## 图文导出

```text
当前已渲染的 Web 主页面
  → 去掉表单、脚本及嵌入页面
  → 不可变的结构化快照（段落、标题、链接、列表、表格、图片）
  → 原有外部 AI 整理（可选、独立版本绑定）
  → Markdown + JSON + 本地图片 ZIP
```

ZIP 保存到系统下载目录下的 `scholay today` 文件夹，不覆盖同名导出。包含：

- `article.md`：Obsidian 可读 Markdown、元数据与相对图片引用。
- `article.json`：带稳定块 ID 的结构化内容及图片清单。
- `manifest.json`：来源、抓取时间、完整性说明、图片 SHA-256 和失败原因。
- `assets/`：本地图片文件。
- `ai-formatted.md`（可选）：仅附带与同一抓取快照匹配的 AI 稿件；图片以原文顺序索引附在末尾，不声称 AI 已分析图片。

普通导出不调用 AI、不消耗模型额度。AI 密钥与现有生成流程保持不变。Reading 导出使用本地缓存，可能只是摘要；Web 导出才抓取当前网页正文。旧 AI 稿件如果没有结构化快照，需要在 Web 模式重新抓取，不能把旧稿与另一页面的图片混装。

单次最多 40 张图、每张 6 MB、总图片 64 MB、图片阶段最多 80 秒，4 路并发。只下载公开 HTTP(S) 地址，拒绝内网地址、凭证 URL、SVG 和伪装成图片的登录页面。受限图片不绕过登录，保留原链接和缺图原因。

边界：不保证后续分页、附件、内嵌 iframe、未展开的隐藏内容或复杂表格版式完整；生成包里的图片可离线使用，但目前没有独立的应用内永久素材管理器。
