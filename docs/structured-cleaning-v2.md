# 文库与结构化清洗规范 v2

## 文库展示

- 只展示有已清洗文档的订阅目录，保留通向有内容子目录的父级；未分类为零时不显示。
- 搜索只过滤文档，不改变目录树。目录或搜索范围变化后，详情始终显示该范围内的文档。
- 目录、列表和正文支持独立滚动；两处分隔条可拖动，宽度保存在独立的 `scholay.files.panes.v1` 偏好中。
- 三篇内置排版示例独立于真实文库。空文库首次进入展示示例，“全部已清洗”仍为零；示例不写数据库、不访问原文、不创建订阅、不进入清洗任务。真实文档存在时默认展示真实文库。
- 旧版清洗结果仍可阅读，并标注“清洗规范待更新”。打开文库不会自动清洗或触发 AI。

## 清洗契约

这是确定性的结构转换，不是 AI 摘要、翻译或事实核验。只依据已有内容，不编造标题、论据、图注、引用或缺失的表格值；不删除可能有意义的重复段落。

1. 来源优先级：已保存的原始网页快照、全文提取缓存、公开网页补抓、RSS 原始内容。补抓仍由应用执行，不复用账号或 Cookie，不执行远程脚本。失败回退保留明确警告。
2. 移除脚本、表单、导航、页脚，以及具有明确隐藏属性或内联隐藏样式的节点。不能可靠判断的内容保留，不做激进的关键词删除。
3. 保留标题级别、段落顺序、链接、编号列表的起始值和显式编号、嵌套列表、多段引用、代码缩进与语言标签。引用和列表中的图片仍使用快照绑定的图片记录，导出时可替换成包内路径。
4. 表格转成 Markdown 表格；合并单元格和嵌套表格无法完整还原时给出警告，不承诺版式保真。
5. 少于 80 个估算字词时提示可能只是摘要；超过 800 个估算字词且没有标题时提示未识别分节；截断和旧版快照的结构限制必须保留。阈值只产生提示，不拒收短文，不生成虚构章节。
6. 清洗生成新的不可变 `clean-*` 快照，不覆盖原始网页快照。以前的清洗结果不再成为下一次清洗的输入证据。图片只保留引用和来源，不宣称已下载。
7. 保存前复核文章输入和来源快照是否改变；改变则拒绝本次覆盖并提示重试。快照和规范清洗记录在同一事务中提交，失败不会留下半份结果。

## 生命周期与兼容

结构化文档版本和清洗规范版本均为 2。原有文档可以继续读取；在用户通过 Agent 确认并提交清洗作业时，默认候选包含尚未清洗或清洗版本过期的文章，仍默认只选未读、最新优先。明确给出文章 ID 可选择已读文章；`force` 保留既有语义。

继续使用预览 → 确认选片 → 提交 → 轮询的流程。上限 200 篇、并发 3、单篇 45 秒和整体 30 分钟限制不变。不修改已读、收藏、稍后读、订阅或独立 AI 稿件。不迁移数据库、不批量重写旧文档。

旧快照中已经丢失的编号与引用层级无法凭空恢复。使用这类快照清洗会明确提示；需要重新抓取原文才能获得新的结构。

## 验证

```sh
pnpm test
pnpm build
cargo test --workspace --locked
```

隔离界面预览：`pnpm dev` 后打开 `/qa/library-calendar.html`，可切换文库、学术年历、昔日学术、浅色/深色和 920/1280 像素容器。预览只使用内置示例、静态日历种子和内存 IPC，不读写本机资料库。

日历与详情分割线现在常驻显示，并带居中把手；悬停、拖动和键盘焦点显示强调色。支持左右方向键、Shift 加速以及 Home/End 边界定位，失焦结束拖动。
