# RSS 多标签阅读区

## 使用规则

- 点击文章打开或激活唯一标签；Ctrl/Cmd + 点击、中键点击在后台打开，不提前标记已读或创建网页。
- 标签与列表范围独立。切换订阅、目录、筛选、工作台不会清空标签；文章操作始终针对活动标签。
- 标签支持关闭、中键关闭、右键关闭其他／右侧／全部，以及溢出列表。关闭当前标签优先回到最近使用的标签。
- RSS 工作台支持 Ctrl/Cmd + W、Ctrl + Tab、Ctrl + Shift + Tab、Ctrl/Cmd + Shift + T。弹窗与菜单优先处理键盘。最近关闭记录最多 20 条，不跨重启保存。
- 每个标签独立保存 Web／Markdown／RSS original 模式、全文／翻译、RSS 与 Markdown 滚动、源码／预览、目录状态和网页缩放。

## 状态与原生网页

`src/lib/readerTabs.ts` 是标签状态的唯一来源；`selectedArticleId` 只是活动标签的兼容投影。会话保存至独立的版本化键 `scholay.reader-tabs.v1`，不修改文章数据库或旧阅读偏好。恢复时仅剔除明确不存在的文章；暂时读取失败不会丢弃标签。恢复本身不执行 AI、全文提取或标记已读。

`src-tauri/src/page_view.rs` 为每个网页保存唯一实例代次、请求、URL、缩放与实际使用顺序。RSS 网页最多保留 10 个；热榜和标签授权拥有独立实例，不计入该限额。后台新标签保持惰性，切换到 Markdown／RSS 仅隐藏网页。第 11 个 RSS 网页淘汰最久未使用、不可见且未抓取的实例，不删除标签或任何文章内容。

缓存内切回保留网页运行状态、滚动及历史；淘汰后只重建最近网址与缩放，并显示重新加载提示。网页运行状态、表单及历史不跨淘汰或重启恢复。关闭标签立即释放网页。所有控制及事件均绑定实例／请求，迟到回调不能操作新实例。

全应用同一时刻只显示一个原生内容网页。标签栏和工具栏位于网页矩形以外；弹窗、菜单、AI 抽屉覆盖时隐藏网页。远程网页没有新增 Tauri IPC 权限。macOS 的应用内键盘处理补足 WKWebView 焦点下的 Ctrl + Tab，其余原生菜单行为与工作台数字快捷键保留。

AI 格式化任务由 `src/lib/formatJobs.ts` 按文章与运行标识管理。离开标签取消等待打开；抓取期间短暂锁定切换及所属标签关闭；模型阶段可切换或关闭，完成后只写回原文章，不抢焦点或重新打开标签。失败状态在本次运行中可重新打开后查看和重试。

## 本地复验

```sh
pnpm test
pnpm build
cargo test --workspace --locked
cargo run --locked -p papr --features reader-tabs-smoke --example reader-tabs-smoke
```

原生 smoke 打开独立测试窗口和本机临时 HTTP 服务，使用合成文章及独立浏览器标识，不访问用户数据库、外部账户或模型。成功输出 `READER_TABS_SMOKE_PASSED`，失败以非零状态退出；60 秒未完成会终止。需要本机端口和桌面窗口权限。

视觉预览：运行 `pnpm dev -- --port 1430`，打开 `/qa/rss-tabs.html`。它使用正式组件及内存合成数据，不会操作真实文章。浏览器预览不含原生网页，不能代替上述 smoke。
