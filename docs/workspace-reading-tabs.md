# 独立工作台阅读标签

RSS、文库、热榜各自拥有独立的右侧标签栏。按用户最新反馈取消可折叠标签组：不显示其他工作台的标签或计数，不通过阅读标签切换功能。使用左侧工作区入口或原有数字快捷键切换功能，各工作台保留上次阅读位置。

## 交互

- 当前工作台只显示自己的内容标签；新标签追加到本工作台末尾。没有组头、折叠箭头或跨功能入口。
- 点击列表内容打开或激活已有标签；Ctrl/Cmd 点击和中键点击后台打开。后台打开不创建网页、不标记 RSS 已读、不运行 AI。
- 切换订阅源、目录、榜单和搜索条件不改变右侧当前阅读内容。仅在当前列表包含该内容时高亮对应行。
- 关闭按钮或中键关闭标签。关闭当前标签只在当前工作台按最近使用记录回退；没有使用记录时选相邻标签。关闭最后一个标签显示当前工作台空态，不跳到其他功能、不关闭应用。
- 标签右键菜单支持关闭、关闭其他、关闭右侧、关闭全部；所有操作范围仅限当前工作台，绝不关闭其他功能中的标签。
- 右上角标签列表始终可达。标签栏仅横向滚动，打开/切换标签及改变窗口宽度时自动露出当前标签与关闭按钮。
- Ctrl/Cmd W 关闭当前标签；Ctrl Tab / Ctrl Shift Tab 只在当前工作台循环；Ctrl/Cmd Shift T 恢复当前工作台最近关闭标签，没有记录时不操作其他功能的历史。每个工作台各保留最多 20 条关闭记录，仅本次运行有效。
- 快捷键只在 RSS、文库、热榜工作台启用。菜单、弹窗、AI 抽屉和抓取锁优先；原生网页焦点下沿用宿主键盘转发，不向远程页面开放 IPC。
- `j/k` 导航当前列表，使用同一套打开/激活逻辑。文库源码输入区域和其他输入控件不拦截文字输入。

## 状态与持久化

`WorkspaceReadingTabs` 复用标签样式和代码，但严格按工作台过滤展示。`src/lib/readingGroups.ts` 保留内部所有者分类以兼容已有会话，不复制 RSS 文章状态：RSS 仍由 `useReaderTabs` 管理，兼容既有 `selectedArticleId` 映射。文库和热榜使用独立的资源键、运行时标签 ID 和阅读状态。该状态层不再发布跨工作台跳转事件。

- RSS 保留原有 Web / Markdown / RSS 原文、翻译、全文、目录和滚动状态。
- 文库保存预览/源码、各自滚动和目录状态。读取完整已清洗文档集合校验恢复标签；失效文档直接跳过，数据库读取失败不冒充删除。
- 热榜保存摘要/Web、摘要滚动、最近网址和缩放。标签只保存公开榜单条目及来源展示字段，不保存授权配置。
- 文库/热榜继续使用版本化键 `scholay.reading-groups.v1`，读取旧会话时忽略废弃的折叠字段，保留已打开内容及各自状态。RSS 继续使用 `scholay.reader-tabs.v1`，工作台继续使用 `papr.workspace.v2`。不迁移或覆盖全局阅读偏好，不改文章数据库结构。
- 重启生成新的原生实例身份，按需重建网页；不保存网页运行状态或历史栈，也不会触发 AI/清洗任务。

## 原生网页生命周期

RSS 与热榜在后台共用最多 10 个原生网页的 LRU 资源池，以实际使用顺序而非标签排列顺序淘汰；资源限制不合并标签栏、活动标签或关闭历史。`rss-*` / `hot-*` 为阅读实例；旧工作台 `page-view` 和授权 `labels-page` 不计入缓存。

切换标签、工作台、摘要/Markdown 模式只隐藏网页，缓存内的滚动、历史和运行状态保留。淘汰保留标签及网址/缩放，返回时按最近网址重建并提示。关闭标签立即退休请求身份并排队释放原生实例。全应用同一时间最多展示一个内容网页。

`useReadingPages` 在应用生命周期内观察 URL、缩放和淘汰事件，要求实例 ID、请求代次和原生代次匹配。关闭后重开产生新身份，迟到事件不会写入新标签。抓取实例和当前可见实例不可淘汰；RSS 原有 AI 任务生命周期与锁定规则不变。
