# 标签工作区：时间快照、分类标签与持久授权

RSS / 热榜 / 标签 独立，快捷键 ⌘/Ctrl + 1 / 2 / 3。沿用 RSS 的字体、密度、纸面主题和侧栏；不改 RSS 数据库、文章内容或热榜缓存。

## 统一视图

三栏结构为「平台 → 固定八小时快照 → 多类标签信息」。中栏按北京时间固定为每天 00–08、08–16、16–24 点三档，无时间筛选、自定义日期或区间汇总。最新一期固定在顶部，下面仅滚动历史。右栏直接展示分类标签卡片，不再显示整块标题、总体统计、覆盖说明和搜索筛选；采集元数据保留在条目展开详情。官方网页只在主动授权时嵌入；来源链接可用系统浏览器打开。

- 每一期保留各平台在该档内最近一次成功采集的榜单，各榜按原排名展示；同一档内再次刷新只更新这一期，不增加时间行。不同时间档的平台数据不混合为同一期。
- 全部平台视图按时间档合并平台，但不合并跨平台标签或相加流量指标。
- 已有平台周期原样保留；本机时间轴指采集时间，不冒充平台历史接口。未采集的过去、休眠/关闭/失败的空档不补造数据。
- 热榜和标签均有两条可拖分隔线（热榜概览只有侧栏边界），宽度按工作区分别保存，与 RSS 宽度偏好隔离。

## 授权

右上角「授权管理」或平台卡片「管理授权」：

1. 「扫码 / 登录授权」打开官方页面，平台的扫码、验证码、协议确认由用户完成。
2. 「保存授权」将本平台 Cookie 安全保存，返回本机管理界面。也可直接粘贴 Cookie 请求头或浏览器 Cookie JSON 数组。
3. 关闭授权面板后同步验证。后续后台采集自动恢复保存的 Cookie；成功采集后更新已有的安全备份以保留会话轮换。
4. 「清除本机保存的授权」需二次确认，只删除本应用的安全备份，不注销平台、不清空系统 WebView 的会话。

当前七个平台统一采用 Cookie 会话，没有假设它们提供通用 API Key。界面区分「未保存」「Cookie 已安全保存、可用性待验证」「已过期」「榜单读取成功」。公开榜单读成功不代表已登录。Cookie 的客户端保存不能延长服务端会话寿命，失效时需重新授权。

- macOS：系统钥匙串；原生 WebKit 接口保留域名前点、HttpOnly、Secure、SameSite 和有效期，避免通用 Cookie 包装器规范化域名造成登录丢失。
- Windows：Credential Manager 分块保存（每块 2048 字节，最多 64 块），新代次写完才替换索引。WebView2 进程内、固定的 Cookie 接口按本站 URL 读写，无调试端口。Windows 代码不等于已完成 Windows 实机验收。
- Cookie 值不回传 UI（粘贴导入除外）、不写 SQLite/localStorage/日志、不会进入 RSS、MCP、AI 或导出文件。导入字段保存后清空；错误消息不包含原始凭据。
- 域名按平台白名单校验；最多 200 个 Cookie / 128 KB。没有安全存储支持时不降级成明文文件。

## 后台采集与缓存

原生采集窗口与阅读器的单个 page-view 分离，初始隐藏，无远程 IPC、无弹窗/下载/脚本对话框；窗口状态记忆插件显式排除 label-collector-*，不允许它把采集窗口显示出来或保存临时窗口状态。

固定、只读 DOM 适配器仅读取已验证来源和路径的榜单容器，不读取密码、账户资料、私信、作品或收益。来源验证在读取前后执行，输出字段和数量受限。不使用 AI 推断流量。

采集串行、超时退出并销毁临时窗口；切换工作区、平台或打开授权面板时取消旧任务。标签板活跃且不在授权时，进入新的八小时时间档自动同步所选平台（全部平台视图同步所有已适配平台）；恢复到前台时检查是否缺少当前档。当前档已有成功数据时自动采集复用它，手动同步仍可刷新本期。每次成功保留原始观测，并更新该平台对应时间档；失败不写空快照、不清旧数据。应用关闭期间没有后台采集服务，不承诺关闭期间也能收齐每天三份。

独立 IndexedDB 历史库 scholay-label-history 持久保存公开榜单，版本 2 保留原 captures 存储，新增按平台和时间档索引的 editions。升级时从旧原始记录派生每档最新观测，不删除或修改原记录。兼容已有 scholay.labels.snapshots.v1 的最近快照：逐字段过滤后，以平台和原采集时间幂等迁入，不把旧数据重标为今天；小型最近缓存继续作为兼容回退。不会改动 RSS SQLite、MCP、AI、授权存储或热榜缓存。授权表单内容不持久化在前端。

时间列表按完整时间档每批读取 30 期，滚动接近底部自动加载更早历史，也保留手动加载入口；分页不会把同档的不同平台拆开，不受原始记录查询的 5000 条上限影响。分类标签每批显示 50 条。写入失败明确提示未保存，不将内存数据显示成历史已落盘。
